# Unified AI Credit Bank

This repository now contains a starter monorepo for the Unified AI Credit Bank MVP.

## Included
- Next.js dashboard frontend
- Express API backend
- Shared package for domain types
- Docker Compose setup for PostgreSQL and Redis

## Getting started
1. Install dependencies: `pnpm install`
2. Start services: `docker compose up -d`
3. Start the app: `pnpm dev`

The frontend runs on http://localhost:3000 and the API runs on http://localhost:4000.
